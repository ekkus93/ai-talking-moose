# Talking Moose AI v0.1.0

Initial V1 release candidate for macOS.

## Highlights

- Retro desktop Talking Moose character implemented with Tauri, React, TypeScript, and Rust.
- Local Moonshine Tiny Streaming ASR by default for new profiles, with optional Small Streaming and explicitly selected Gemini Live cloud audio.
- Rust-owned audio playback, mouth animation, barge-in, mute/dismiss privacy shutdown, and device diagnostics.
- Gemini conversational AI and standalone TTS with secure Google API key storage in macOS Keychain.
- Conservative defaults for memory, transcript retention, and active-application observation.
- Bounded queues, provider/resource teardown, privacy-safe logging, persistence migrations, safe tools, ambient policy, and release hardening.

## Distribution

The release workflow produces separate signed/notarized Apple Silicon (`arm64`) and Intel (`x86_64`) DMGs plus zipped `.app` bundles and SHA-256 checksum manifests.

Minimum deployment target is macOS 10.15 on Intel. Apple Silicon Macs require macOS 11 or later by platform availability.
