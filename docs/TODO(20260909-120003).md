**Companion specification:** `docs/SPEC(20260909-120003).md`
**Baseline:** `80027a70815bfa8db6c9faa03b3a8e7501f2fe4d` (`master`, 2026-09-09)
**Status:** Active implementation plan
**Scope:** Add KittenTTS Mini 0.8 as a CPU-first local standalone TTS option while preserving Google Gemini TTS, Gemini Live native audio, the existing Rust/CPAL playback path, strict privacy boundaries, and permissive distribution posture.

Task IDs use the `KTT-###` prefix (**KittenTTS Local TTS**).

This tracker deliberately separates **model selection** from **runtime/phonemizer selection**. KittenTTS Mini 0.8 is the selected model family. The production runtime/G2P stack MUST NOT be frozen until P0 proves exact compatibility and licensing.
