# KittenTTS P0 feasibility harness

This crate is an isolated pre-integration probe for `docs/TODO(20260909-120003).md` P0.

It is intentionally outside `src-tauri` and is not part of the application build.

Frozen direct candidate dependencies:

- `kittentts = 0.4.1`, `default-features = false`;
- `piper-plus-g2p = 0.4.0`, `default-features = false`, English only.

`Cargo.lock` was generated by KittenTTS P0 feasibility run `34397792164` and committed as `a6ffebed68112cd5adbbfcf8f7dcc59ae84bf821`. Production selection still depends on the matrix license inventory, official-vs-candidate model-input comparison, and real CPU synthesis evidence.

The `reference_ipa.py` oracle deliberately uses the upstream GPL eSpeak/phonemizer stack only inside explicit P0 CI. It must never become an application or release dependency.

The candidate Rust path uses the pinned CMUdict-derived BSD-style dictionary, produces IPA without eSpeak, and feeds that IPA to Kitten ONNX inference. The comparison is made at model token IDs, not raw IPA spelling.
